# Claims we avoid

Do not claim that Echo guarantees organizational truth, that an AI knows which source is true, that the entire company is monitored, or that Bedrock powers a live demo without verified runtime access.

Use: “Echo detects potential knowledge changes and routes them through human verification.”

Use: “The AI compares evidence and proposes a change; a human verifies it.”

For this local run: “The demo uses explicit local rules. Groq and Bedrock adapters are included but have not been invoked.”

Do not describe CDK-defined controls as deployed, scheduled checks as continuous monitoring, a planned integration as connected, or this build as production-certified. Review the status and security documents before making release claims.
